# Lila Home — 设备清单（手机填写版）

> 给 At 在手机上直接回的版本。不用填表，按下面格式每台设备回一行就行。
> 不知道的写“不知道”，不要猜。账号、密码、Token、配对码一律不要发。

## 每台设备回一行

格式：房间 — 类型 — 品牌 — 型号 — 怎么联网

例如：客厅 — 灯 — 小米 — 米家吸顶灯 Pro — Wi-Fi

### 1. 路由器

房间 — 路由器 — 品牌 — 型号 — 联网方式：

### 2. 音响

房间 — 音响 — 品牌 — 型号 — 联网方式：

### 3. 灯光（有几盏写几行）

房间 — 灯 — 品牌 — 型号 — 联网方式：

### 4. 空调

房间 — 空调 — 品牌 — 型号 — 联网方式（Wi-Fi / 红外遥控）：

### 5. 热水器

房间 — 热水器 — 品牌 — 型号 — 联网方式：

### 6. 其他（有就写，没有跳过）

房间 — 类型 — 品牌 — 型号 — 联网方式：

## 再回两句就行

- 家里有没有网关 / 中枢（比如小米中枢网关、Zigbee 网关）？有的话写品牌型号，没有写“没有”。
- 小米 / 华为智慧生活 / 美居这三个账号，你愿不愿意授权给 Home Assistant 接入？回“愿意 / 只接某个 / 先不接”就行，不用发账号密码。

## 拿到清单后我做的事

按型号逐台核实 Home Assistant 能不能接、走哪条接入路径；能接的接进来，不能接的如实告诉你原因，不编“已适配”。
