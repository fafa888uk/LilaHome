# Lila Home — 设备清点表模板（Stage 0-04）

> 文档：`docs/audit/DEVICE_INVENTORY_TEMPLATE.md`
> 用途：用户逐台填写家中真实设备，供 Stage 1 做型号级兼容性核实。
> **本文件为空白模板，不含任何真实设备。不得填写未经核实的设备、不得虚构测试成功。**
> 填写说明：每台设备一行；不知道的字段写 UNKNOWN，不要猜；Token/密码/配对码一律不要写进本表，另走本地秘密管理。

## 必填字段说明

| 字段 | 说明 |
|---|---|
| 房间 | 设备所在房间，用于房间管理中心分组 |
| 设备类型 | 路由器 / 音响 / 灯光 / 空调 / 热水器 / 其他 |
| 品牌 | 小米 / 米家 / 华为 / 鸿蒙智联 / Apple HomeKit / 美的 / 其他（写全称） |
| 型号 | 机身/说明书/厂商 App 里的完整型号，不知道写 UNKNOWN |
| 固件版本 | 厂商 App 里显示的固件版本，不知道写 UNKNOWN |
| 联网方式 | Wi-Fi / Zigbee / BLE / Thread / 红外 / 蓝牙 / 有线 |
| 协议 | Matter / Zigbee / MQTT / HomeKit / AirPlay / DLNA / 厂商 LAN API / 厂商云 API / 红外 |
| HA 接入路径 | Stage 1 核实后填，如 `midea` / `xiaomi_miot` / Matter / HomeKit Device；Stage 0 一律写“待核实” |
| 兼容等级 | Stage 1 核实后填 A/B/C/D；Stage 0 一律写“待验证” |
